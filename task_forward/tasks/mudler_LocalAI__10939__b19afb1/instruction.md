```
Bonsai gallery models reference unpublished backend OCI images

**LocalAI version:**
v4.7.1

**Environment, CPU architecture, OS, and Version:**

- `Linux kura 6.12.91-production+truenas #1 SMP PREEMPT_DYNAMIC Tue Jun  2 19:45:50 UTC 2026 x86_64 GNU/Linux`
- TrueNAS SCALE
- LocalAI Intel oneAPI image
- GPU: Intel Arc A310 4 GB
- CPU: Intel Xeon E-2124G with AVX2

**Describe the bug**
Installing any of the Bonsai gallery models fails because the backend gallery references OCI image tags that do not exist in either the Quay registry or the Docker Hub mirror.

The model installation command was:

`./local-ai models install ternary-bonsai-8b`

LocalAI selected this backend:

`intel-sycl-f16-bonsai`

It attempted to download:

`quay.io/go-skynet/local-ai-backends:latest-gpu-intel-sycl-f16-bonsai`

The registry returned:

`MANIFEST_UNKNOWN: manifest unknown`

LocalAI also tried these fallback tags, which were missing:

`quay.io/go-skynet/local-ai-backends:master-gpu-intel-sycl-f16-bonsai`
`quay.io/go-skynet/local-ai-backends:master-gpu-intel-sycl-f16-bonsai-development`

I checked the CPU, Vulkan, and Intel Bonsai backend tags directly:

`docker manifest inspect quay.io/go-skynet/local-ai-backends:latest-cpu-bonsai`
`docker manifest inspect quay.io/go-skynet/local-ai-backends:latest-gpu-vulkan-bonsai`
`docker manifest inspect quay.io/go-skynet/local-ai-backends:latest-gpu-intel-sycl-f16-bonsai`

`docker manifest inspect localai/localai-backends:latest-cpu-bonsai`

All three are missing there as well.

Backend images advertised by the Bonsai meta-backend should exist in the configured registry or mirror, allowing gallery models such as ternary-bonsai-8b and bonsai-8b-1bit to install.
  ```
