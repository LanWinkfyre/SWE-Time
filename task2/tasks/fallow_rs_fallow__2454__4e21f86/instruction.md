# Recover the symbolic verification state this change produces

A regression report was filed against `fallow-rs/fallow`.  The report is quoted verbatim below.

## Report

```
Coverage maps written by v8-to-istanbul (c8, nyc) are rejected with exit 2

`fallow health --coverage` aborts with exit 2 on a coverage map produced by `v8-to-istanbul`, which is what c8, nyc in v8 mode, and older vitest versions write.

```
fallow health --complexity --coverage coverage-final.json --format json --quiet
{"error":true,"message":"coverage: failed to parse coverage data from .../coverage-final.json: invalid value: integer `-1`, expected u32 at line 145 column 24","exit_code":2}
```

## Cause

`v8-to-istanbul` 9.2.0 emits a negative column for an implicit else branch location. From a map generated by running real V8 coverage through the converter:

```json
"2": {
  "type": "branch",
  "line": 5,
  "loc": { "start": { "line": 5, "column": -1 }, "end": { "line": 6, "column": 0 } },
  "locations": [ { "start": { "line": 5, "column": -1 }, "end": { "line": 6, "column": 0 } } ]
}
```

Position columns deserialize as `u32`, so the whole map is rejected before anything is read. The field is in `branchMap`, which the CRAP path never consults: one unreadable coordinate in a section fallow ignores costs the user the entire feature.

## Reproduction

```js
import v8toIstanbul from 'v8-to-istanbul';
// run any module under Profiler.startPreciseCoverage, then:
const converter = v8toIstanbul(file, 0);
await converter.load();
converter.applyCoverage(entry.functions);
writeFileSync('coverage-final.json', JSON.stringify(converter.toIstanbul()));
```

A module with a bare `if` and no `else` is enough. One branch location in the resulting map carries `column: -1`.

## What needs deciding

Clamping a negative coordinate to zero and ignoring `branchMap` entirely are both defensible, since neither affects any value fallow reports. The position type lives in the shared coverage types crate rather than here, so a lenient deserializer is a change in that crate plus a version bump, unless fallow skips the section before it reaches the strict type.

Worth noting for whoever picks this up: `--coverage`'s help text says "Requires Istanbul format (not v8/c8 native format)". That is true and still misleading, because the file c8 writes at the end of a run is Istanbul format, and it is exactly the file that fails here.
```
